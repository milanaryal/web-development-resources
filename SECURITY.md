# Security Policy

This repository is a curated list and does not distribute executable software.
Its main security risks are malicious, compromised, impersonating, or misleading
external links.

For a non-sensitive problem, open an issue identifying the entry and the evidence
for the concern. Do not include credentials, private data, exploit details, or
other sensitive information in a public issue. If a report is sensitive, contact
the maintainer through their GitHub profile before sharing details.

Security reports for a listed resource should also be sent to that project's own
security contact. Inclusion in this list is not a security endorsement.
